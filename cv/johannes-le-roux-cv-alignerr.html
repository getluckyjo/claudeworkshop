Evaluating AI output criticallyWhere this role fits

The recurring job in my work is catching where a plausible-looking answer is wrong: a total that triple-counts because the file repeats each product per pack size; a subscription model that only hits its target if churn is assumed away; a forecast whose margin survives only because working capital was left out.
